# PowerBI Dashboard de Locacao de Veiculos
📊 Relatório Interativo - Power BI
Este repositório contém os arquivos de estrutura, layout e visuais personalizados de um painel interativo desenvolvido no Power BI. O projeto foi estruturado para oferecer análise de dados dinâmica, navegação intuitiva e suporte a filtros avançados de pesquisa.

📌 Sobre o Projeto
O objetivo deste relatório é consolidar informações estratégicas através de um painel visualmente otimizado. Ele conta com plano de fundo estilizado, visuais customizados para busca de texto e segmentação de dados dinâmica para facilitação da tomada de decisão.

✨ Recursos do Painel
Filtros de Pesquisa: Recursos de busca textual para localização rápida de atributos.

Layout Estruturado: Design visual padronizado com recursos gráficos de fundo para melhor usabilidade.

Interatividade: Relacionamento entre dados e navegação fluida entre os elementos da página.

🛠️ Tecnologias Utilizadas
Power BI Desktop (Modelagem, visualização e estrutura do painel)

Visuais Customizados do Power BI

JSON e XML (Estrutura e configurações do relatório)
